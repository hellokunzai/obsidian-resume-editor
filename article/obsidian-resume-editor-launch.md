# Obsidian 里写简历是什么体验：左边填表，右边出 PDF，全程不联网

# 🔔 开篇导语

去年换工作那阵，我的简历躺在三个地方：一份 Word 在桌面，一份 PDF 在微信文件传输助手，还有一份字段已经对不上的在线简历。

改一次手机号，要改三遍。

我是写 Java 的，平时笔记、读书摘录、理财记录全在 Obsidian 里。有天突然想：简历为什么不能也放进库里？

于是有了 Resume Editor——一个 Obsidian 插件。左边填表单，右边实时预览，改完直接导出 PDF / HTML / DOCX / LaTeX，全程在本机跑，不联网。

# 📖 它是什么

一句话：**Obsidian 里的表单式简历编辑器**。

几个硬信息：

- 插件名 Resume Editor，当前版本 `0.10.10`
- 要求 Obsidian `1.11.4` 以上
- 桌面端、手机、平板都能跑（`isDesktopOnly: false`）
- MIT 协议，源码公开
- 离线运行，没有 AI 功能，也没有云同步

它用 `.resume` 作为自己的文件格式——每份简历就是一个结构化 JSON 文件。我在插件里把这个扩展名注册给了 Obsidian：`registerExtensions(["resume"], VIEW_TYPE_RESUME)`。所以点开 `.resume` 文件会直接进编辑器，跟 `.canvas` 一样复用同一个标签页，不会重复开。

简历数据也因为这个格式变得好处理：所有内容都是结构化字段，想导出成什么样子，就按什么格式重新组织一遍。

# 🚀 核心功能

## 一、填表就行

姓名、电话、邮箱、求职状态、教育、工作、项目、技能、自我评价、证书、自定义模块，一格一格填。预览区实时更新，敲一个字就变。

模块可以拖拽排序、折叠、单独隐藏。想给 A 公司看项目经历、给 B 公司看证书，复制两份文件各调各的就行。

## 二、12 套模板，换着试

单栏、双栏、学术、经典、时间轴、瑞士、现代、极简、左右分栏、优雅、创意、杂志风。

模板是配置驱动的：`src/render/templates/registry.ts` 里加一行，再在 `template.ts` 补一段 CSS，就是一套新模板，不用动其它地方。

有一点我特意做了：**默认模板只作用于新建的简历**。已保存的文件会记住自己的 `templateId`，所以你在设置里换了默认模板，旧简历的样子不会被覆盖。

> 📷 **配图建议**：横图，12 套模板的缩略图拼成一排或九宫格

## 三、每份简历有自己的样式

样式不是全局的，而是存在每份简历内部：

| 项目 | 可调范围 |
|---|---|
| 主题色 | 12 色板 |
| 正文字号 | 11–16 px |
| 行距 | 1.2–2.0 |
| 模块间距 | 8–32 px |
| 页边距 | 16–48 px |
| 段间距 | 0–16 px |
| 字体 | 可自定义字体栈 |

这些值写在笔记的配置块里，跟着文件走。

还有个我自己用得最多的开关：**显示 A4 分页线**。内容超过一页时，预览区会画出 A4 高度（1123px @96dpi）的横向虚线，状态栏告诉你总共几页。想压成一页，就调字号、行距、模块间距，看着虚线调，不用反复导出 PDF 去试。

## 四、四种导出，全在本机

- **PDF** — 基于 `html2pdf.js`（html2canvas + jsPDF），点击即落盘
- **HTML** — 模板 HTML + 内联样式的单文件，双击就能看
- **DOCX** — 自研的零依赖 OOXML 生成器
- **LaTeX** — 生成 `.tex`，带 `CJKutf8` 中文支持

头像支持尺寸、宽高比（1:1 / 4:5 / 3:4）、圆角设置；联系方式可以自己加字段，图标 + 标签 + 值。

# 🛠 技术上踩的两个坑

只讲两件值得说的事，都是被现实逼出来的。

## 坑一：DOCX 库把我挡在了上架门外

最早我用的是现成的 docx 库，功能没问题。但打包进 `main.js` 之后，社区市场的自动扫描报了一条：`new Function`。

动态构造函数在插件审核里是阻断项。要么砍掉 DOCX 导出，要么自己写。

我选了自己写。现在 `src/export/docx-core.ts` 有 851 行，做的事是：

1. 手写 WordprocessingML —— `document.xml`、`styles.xml`、`[Content_Types].xml`、`_rels/document.xml.rels`、`docProps/*.xml`
2. 自己实现 CRC32（多项式 `0xedb88320`）
3. 自己写 ZIP 打包，用 **store 模式**（method 0，不压缩）——简历文档本来就小，压缩省不了多少，不压缩反而省掉一整个依赖
4. 图片通过 `ImageLoader` 回调注入，核心模块不依赖 Obsidian，能单独在 Node 里跑测试

零依赖、无 `eval`、无 `new Function`，审核过了。副作用是 DOCX 导出样式终于能和预览对得上了——因为两边现在都是我在写。

## 坑二：PDF 导出和那个「打印对话框」

Obsidian 插件导出 PDF，常见做法是开一个隐藏 webview 调 `printToPDF`，或者弹 `window.print()`。前者在部分环境里 webview 标签根本没启用，后者每次都要多点一次确认。

我改成在渲染进程里用 html2pdf.js 直接把 DOM 渲染成 PDF，再用 `app.vault.adapter.writeBinary` 写进 vault。点击即落盘，中间没有任何对话框。

顺带一提，这里也有合规要求：不能用 `innerHTML` 拼接 HTML（会被静态扫描判成 XSS 风险）。所以代码里是先用 `DOMParser` 以 `text/html` 模式解析（这个模式不执行脚本），再把节点搬进离屏容器。

类似的还有移动端 A4 缩放：动态值用 `setCssProps` 写 CSS 变量，静态规则放 `styles.css`，不动态创建 `<style>` 元素——`no-static-styles-assignment` 同样是一条审核项。

> 💡 **核心总结**：社区市场的合规要求不是走流程，它会实打实改变你的技术选型。

# 📦 怎么装

**新用户：**

1. 在 Obsidian 里安装 **BRAT** 插件
2. BRAT 设置 → Add Beta Plugin → 填仓库 `hellokunzai/obsidian-resume-editor`
3. 回到 设置 → 第三方插件，启用 **Resume Editor**

**已经有旧版本的：**

在 BRAT 里点更新就行。

**开始用：**

- 命令面板搜 **新建简历**（New resume），创建一份 `.resume` 文件，默认叫 `新建简历.resume`；重名会自动顺延成 `新建简历 1.resume`
- 在文件列表右键任意文件夹 → **新建简历**，就在那个目录下建
- 想把已有笔记变成简历 → 命令 **标记当前笔记为简历**
- 点开任何 `.resume` 文件，直接进编辑器

导出用编辑器顶部的按钮，或者命令面板里的 **导出简历为 PDF / HTML / DOCX / LaTeX**，文件会写在你当前笔记旁边。

# ❓ 常见问题

**Q：简历数据会传到网上吗？**

不会。编辑、预览、PDF / HTML / LaTeX 导出、存储全是本地操作。唯一例外是 DOCX 导出时，如果你的头像是 `https://` 开头的远程图片，插件会去把那张图拉下来嵌进文档——只请求你指定的那一个 URL。

**Q：手机上能改简历吗？**

能，但布局跟桌面端不一样。手机屏幕窄，编辑和预览不并排显示，用头部的切换按钮来回切（默认进编辑）。预览会渲染 794px 宽的 A4 纸再等比缩放到屏幕宽度，看着跟真纸一样。触屏下拖拽手柄不好使，排序改成了 ↑↓ 按钮。

**Q：换模板会把我调好的样式冲掉吗？**

不会。每份简历存自己的 `templateId` 和 `globalSettings`，新模板只影响新建的文件。

**Q：怎么保证正好一页？**

打开「显示 A4 分页线」，看虚线和总页数提示，再回头调字号、行距、模块间距、页边距。调完直接在预览区看结果，不用反复导出。

# 📋 全文总结

Resume Editor 现在能做的事：在 Obsidian 里用表单写简历，12 套模板，样式按文件独立保存，一键导出 PDF / HTML / DOCX / LaTeX，桌面端和手机端都能用，全程离线。

做下来有两个体会比较深。

一是**工具要把控制权留给用户**。样式存在文件里、模板不覆盖旧文件、自动保存可以关掉——这些算不上「贴心设计」，只是承认我并不知道你的简历该长什么样。

二是**合规会改变技术选型**。我原本以为自己写 OOXML 和 ZIP 属于过度设计，直到看见扫描报告里那行 `new Function`。回头看，那 851 行换来的不只是过审，还有导出样式和预览的完全一致。
